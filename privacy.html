Privacy policy

Effective November 12, 2026

Velum runs entirely on the user's own Mac. It has no server, no account system and no analytics. This policy covers its one connection to Google, which is optional and off by default.

Data accessed

When the user turns on Google sign-in for an account, Velum asks Google for the drive.file scope and uses it only to call the Google Drive API's about endpoint, which returns the account's email address and storage quota (the plan's limit, the storage used, and the part used by Drive). Velum creates and opens no Drive files, so the scope gives it access to none.

How data is used

The email address is used only to check that the sign-in belongs to the account the user chose. The storage figures are shown in Velum's menu bar panel on the same Mac, refreshed about every 30 minutes while the feature is on.

Storage

Google's refresh token is kept in the macOS Keychain on the user's Mac. The storage figures are kept in memory only. Nothing is sent to the developer or to any service other than Google's own sign-in and Drive API.

Sharing

Data is not sold, not used for advertising, not used to train AI models, and not shared with anyone.

Google API Services User Data Policy

Velum's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Turning the feature off in Velum revokes Velum's access at Google and deletes the token from the Mac. Access can also be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be raised through this site's GitHub issues.
