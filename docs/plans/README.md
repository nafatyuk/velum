# Campaign plans

Each campaign is a folder: a plan with buckets, a table of cards and what waits for what, and a `cards/` folder with one card per working session. Paste a card's "Brief" into a new session; it stands on its own. When a card is finished, its "Hand-off" section records what was built and what later cards need to know.
